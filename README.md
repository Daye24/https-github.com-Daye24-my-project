# Australian Electricity Demand Forecasting

## Project Overview

This repository contains a portfolio copy of work completed as part of the **ZZSC9020 Data Science Project**, a collaborative university project investigating how changes in temperature affect electricity demand forecasting in Australia.

The project explored:

* Data cleaning and preprocessing of large time-series datasets
* Exploratory data analysis and feature engineering
* Electricity demand forecasting
* Linear regression modelling and evaluation
* Machine learning and deep learning approaches
* CNN-LSTM modelling
* Hyperparameter tuning and model validation
* Evaluation using metrics including RMSE and R²
* Visualisation and interpretation of model performance
